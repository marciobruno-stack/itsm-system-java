# Requisitos Funcionais (RF)
1. Gestão de ativos (CRUD)
2. Gestão de técnicos (CRUD)
3. Abertura e atribuição automática de tickets
4. Atualização de estado do ticket
5. Listagem e pesquisa de tickets/técnicos

# Requisitos Não-Funcionais (RNF)
1. Desempenho: atribuição de técnico < 1s (1000 tickets)
2. Segurança: autenticação JWT + roles
3. Logs de auditoria
4. Testes unitários com cobertura > 70%
5. Documentação da API com OpenAPI
